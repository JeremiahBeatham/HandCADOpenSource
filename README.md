# HandCADOpenSource

Open-source compliance material for the HandCAD iPhone app.

HandCAD links Open CASCADE Technology (OCCT) 7.9.3, licensed under the GNU LGPL 2.1 with the Open CASCADE Exception 1.0. For each released version of the app, this repository publishes, as a GitHub release:

- the exact OCCT source we built, plus the build script and pinned versions;
- the relink kit: HandCAD's object files and static archives for each platform slice, the license texts and relink instructions.

Material for each version is kept for at least three years after that version's last distribution.

This repository holds no HandCAD application source. No releases have been published yet.
